# FinalYearProject26-27
BolusBuddy — AI-Powered Nutrition &amp; Insulin Bolus Calculator for Type 1 Diabetics

# Overview
BolusBuddy is an Android application that helps type 1 diabetics calculate insulin bolus doses at the mealtimes by scanning food barcodes
or photographing resteraunt meals.

## Project Structure
- `BolusBuddy/` — Kotlin Android app
- `ai_training/` — PyTorch food recognition model
- `backend/` — Python FastAPI server (coming soon)

## Tech Stack
- Android: Kotlin
- Backend: Python + FastAPI
- Database: PostgreSQL
- Infrastructure: Docker + Tailscale
- AI: PyTorch (ResNet50 transfer learning)
- Food Data: Open Food Facts API
